# Pinjam Ruang – Infrastructure

Repository ini berisi dokumentasi dan perencanaan infrastruktur
untuk aplikasi Sistem Peminjaman Ruangan Kampus yang dikembangkan
dalam kegiatan Product Based Learning (PBL).

## Lingkup Infrastruktur
Infrastruktur yang didokumentasikan mencakup:
- Arsitektur aplikasi
- Hubungan antara frontend, backend, dan database
- Rencana deployment aplikasi

## Komponen Sistem
- Backend: ASP.NET Core Web API (.NET 10)
- Frontend: Web Application (JavaScript Framework)
- Database: SQL Server

## Status Implementasi
Saat ini aplikasi masih berjalan pada lingkungan pengembangan (local).
Konfigurasi deployment akan dikembangkan pada tahap selanjutnya.

## Catatan
Repository ini bersifat dokumentatif dan dapat diperluas
sesuai kebutuhan pengembangan berikutnya.
